# Сайт «Природа и человек» — Итоговое сочинение ЕГЭ

Готовый одностраничный сайт для подготовки к итоговому сочинению по разделу **Природа и человек**.

## Как открыть

Просто откройте файл `index.html` в любом браузере (Chrome, Firefox, Edge, Safari).  
Интернет нужен только для загрузки шрифтов Google Fonts. Если интернета нет — сайт всё равно будет работать, просто со стандартными шрифтами.

## Структура файлов

```
priroda-chelovek-site/
├── index.html      — главная страница
├── styles.css      — оформление
├── data.js         — ВСЕ ДАННЫЕ (темы, произведения, аргументы)
├── app.js          — логика отображения
└── README.md       — эта инструкция
```

## Как добавлять аргументы и озвучку

Всё редактируется в файле **`data.js`**.

### Добавить новый аргумент

Откройте `data.js` и добавьте объект в массив `argumentsData`:

```js
{
    id: "arg9",                          // любой уникальный id
    work: "«Название произведения»",
    author: "И. О. Автор",
    tags: ["тег1", "тег2"],              // необязательно
    text: "Текст аргумента...",
    audio: ""                            // пока пусто
}
```

### Добавить озвучку

1. Создайте папку `audio` рядом с `index.html`.
2. Положите туда файл, например `arg1.mp3`.
3. В соответствующем объекте аргумента укажите:

```js
audio: "audio/arg1.mp3"
```

После сохранения файла обновите страницу в браузере — появится обычный аудиоплеер.

### Добавить тему или произведение

Аналогично — просто допишите строку/объект в массивы `topics` или `works` в том же файле `data.js`.

## Содержание сайта

1. **Понятия** — что рассматривается в разделе (человек и природа, природа и цивилизация, смежные вопросы).

3. **Произведения** — 14 ключевых книг с кратким обоснованием, почему они подходят.
4. **Банк аргументов** — 8 готовых развёрнутых аргументов + пустые слоты под озвучку.

## Новая функция: темы с аргументами

В разделе «Примерные темы» нажмите на карточку темы — появится окно с двумя подходящими литературными аргументами. Кнопка «Прослушать аргумент» озвучивает текст средствами браузера (русский голос, если он установлен в системе). Для этого нужен современный браузер; в Chrome и Edge обычно работает лучше всего.

Кнопка «Сохранить тему и аргументы» скачивает отдельный HTML-файл. Его можно открыть без интернета в браузере и распечатать через `Ctrl+P` (или меню «Печать»). Для печати используется чистое оформление без элементов сайта.

Соответствие тем и двух аргументов настраивается в `app.js` в массиве `topicArgumentMap`. Для каждой темы в массиве `topics` указывается пара `id` из `argumentsData`.
